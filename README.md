# Unity Engine Support Lab

A collection of Unity scenes and scripts demonstrating common runtime and performance issues, as well as memory issues encountered in real-world Unity projects.

This repository is intended to showcase practical debugging skills and engine-level understanding relevant to Unity Support Engineering roles.

---

## 🎯 Project Goals

- Reproduce common Unity issues in isolated scenes
- Diagnose problems using Unity tools
- Apply safe production-ready fixes
- Document root causes and prevention strategies
